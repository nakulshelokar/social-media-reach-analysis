# Data Cleaning Automation

## Presented By
**Nakul Shelokar**

## Project Overview

Data Cleaning Automation is a Python-based project that automatically cleans and prepares raw CSV data for analysis.

The project handles common data-quality problems such as missing values, duplicate records, inconsistent text, invalid values, and date formatting.

## Objectives

- Automate the data-cleaning process
- Remove duplicate records
- Handle missing values
- Standardize text and column names
- Validate data
- Convert date columns
- Generate a cleaned dataset ready for analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Regular Expressions
- GitHub

## Cleaning Process

1. Load raw CSV data
2. Standardize column names
3. Remove duplicate records
4. Remove unnecessary spaces
5. Handle missing numerical values
6. Handle missing categorical values
7. Convert date columns
8. Validate data
9. Export cleaned CSV
